## Опис роботи

Практична робота присвячена вивченню системи контролю версій Git
та роботі з віддаленим репозиторієм GitHub через термінал.

У межах роботи було створено ієрархічну структуру директорій
відповідно до пір року та місяців, додано текстові файли,
створено гілки master і test та виконано надсилання змін
до віддаленого репозиторію GitHub.
